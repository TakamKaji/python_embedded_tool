# NotebookLM ローカルファイル同期ツール

このツールは、ローカルPCにあるテキストファイルやMarkdownファイルなどを、Googleの「NotebookLM」へ自動的にアップロード（同期）するためのツールです。
PythonがPCにインストールされていなくても、同梱のセットアップスクリプトで独自のポータブル環境を構築するため、既存のPC環境を汚さずに利用できます。

## 特徴
- **環境を汚さない**: ポータブル版（Embeddable）のPythonをダウンロードして利用するため、PCのシステム環境変数などに影響を与えません。
- **ワンクリックセットアップ**: `setup.bat` を実行するだけで、Pythonのセットアップから必要なライブラリのインストール、Googleアカウントへのログイン（認証）までが全自動で行われます。
- **簡単な同期設定**: `.env` ファイルにノートブックIDと対象フォルダを記述するだけで、対象ファイルのNotebookLMへのアップロードと同期が可能です。
- **対話型実行メニュー**: `run_menu.bat` を実行し、メニューから選ぶだけで直感的に操作できます。

## 使い方

### 1. 初期セットアップ
1. 本ツールのフォルダ一式を任意の場所に配置します。
2. フォルダ内にある `setup.bat` をダブルクリックして実行します。
3. 自動的にPythonやツールのダウンロードが行われた後、ブラウザが開きGoogleアカウントへのログインが求められます。画面の指示に従ってログインを完了させてください。
4. 処理の最後に、あなたがNotebookLM上で作成している「ノートブックの一覧」と「ノートブックID」が画面に表示されます。このIDを控えておいてください。（例: `a1dd0918-XXXX-...`）
5. 「Setup complete.」と表示されたら、エンターキーを押して画面を閉じます。

### 2. 同期設定 (`.env` ファイルの編集)
同期するノートブックとローカルフォルダを指定するために、設定ファイルを編集します。

1. フォルダ内にある `.env.sample` をコピーし、ファイル名を `.env` に変更します。
   （すでに `.env` ファイルが存在する場合はそちらを開いてください）
2. `.env` ファイルをメモ帳などのテキストエディタで開き、以下の項目を設定します。
   ```text
   # 先ほどセットアップ時に控えたノートブックID
   NOTEBOOK_ID="あなたのノートブックID"

   # NotebookLMにアップロードしたいファイルが入っているフォルダの絶対パス
   FOLDER_PATH="C:\path\to\your\folder"

   # 同期するファイルの拡張子 (例: .txt, .md など)
   FILE_EXTENSION=".txt"
   ```

### 3. ファイルの同期実行
設定が完了したら、実際にファイルをNotebookLMへ同期させます。

1. **`run_menu.bat`** をダブルクリックで起動します。
2. コマンドプロンプト画面が開き、メニューが表示されます。
3. 「NotebookLMへファイル同期」に対応する番号を入力して Enterキー を押します。
4. 指定したフォルダ内のファイルが自動的にNotebookLMにアップロードされます。（NotebookLM上に同名のソースがある場合は、古いものを削除して新しいもので上書き更新します）

## 主なファイル構成
- `setup.bat` : 初期環境構築およびログイン・設定用スクリプト。
- `run_menu.bat` : メニュー画面を起動し、同期処理を実行するためのスクリプト。日常的な利用はこちらから行います。
- `.env` : ユーザー固有の同期設定ファイル。
- `.env.sample` : `.env` ファイルの雛形。
- `py/` : 同期処理のメインプログラム (`sync_file.py` など) が格納されています。
- `python-*/` : `setup.bat` 実行後に自動生成される、Python本体と仮想環境。
