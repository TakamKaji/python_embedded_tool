# python_emb_tool

Windows環境において、環境を汚さずにPythonの実行環境を構築し、簡単にスクリプトを実行するためのテンプレートリポジトリです。
プロジェクトごとのベース（ひな形）として利用されることを想定しています。

## 特徴
- **環境を汚さない**: ポータブル版（Embeddable）のPythonをダウンロードして利用するため、PCのシステム環境変数などに影響を与えません。
- **ワンクリックセットアップ**: `setup.bat` を実行するだけで、Pythonのセットアップから必要なライブラリのインストールまでが完結します。
- **対話型実行メニュー**: `run_menu.bat` を実行すると、追加したスクリプトが一覧表示され、番号を選ぶだけで簡単に実行できます。

## 使い方

### 1. 初期セットアップ
1. 本リポジトリをダウンロード（またはクローン）し、任意のフォルダに配置します。
2. フォルダ内にある `setup.bat` をダブルクリックして実行します。
3. 自動的にPythonのダウンロード、展開、および `requirements.txt` に記載されたライブラリのインストールが行われます。
   - ※処理が完了し、「Setup complete.」と表示されるまでお待ちください。

### 2. Pythonコード・ライブラリの追加（開発時）
本リポジトリはテンプレートであるため、具体的な処理をおこなうPythonコードやライブラリは後から追加して使用します。

- **ライブラリの追加**
  必要な外部ライブラリ（pipパッケージ）がある場合は、`requirements.txt` にパッケージ名を追記してください。追記後は再度 `setup.bat` を実行することでインストールされます。
- **Pythonコードの追加**
  作成したPythonスクリプト（`.py`ファイル）は、すべて **`py` フォルダ** の中に配置してください。
  各スクリプトの先頭付近に以下のように `# MENU_TITLE: <メニュー名>` とコメントを記述すると、メニュー画面でわかりやすいタイトルが表示されます。
  ```python
  # MENU_TITLE: サンプル処理の実行
  print("Hello World")
  ```

### 3. スクリプトの実行
開発したコードを実行する場合は、**`run_menu.bat`** をダブルクリックで起動します。

1. コマンドプロンプト画面が開き、`py` フォルダ内にあるスクリプトの一覧がメニュー形式で表示されます。
2. 実行したい機能の番号を入力して Enterキー を押すだけで、該当のPythonスクリプトが実行されます。
3. 処理完了後は再度メニューに戻るため、連続して別の機能を試すことも可能です。

## 主なディレクトリ構成
- `setup.bat` : 初期環境構築スクリプト。
- `run_menu.bat` : スクリプト実行用のメニュー画面起動スクリプト。日常的な利用はこちらから行います。
- `requirements.txt` : プロジェクトで必要なPythonパッケージの一覧。
- `py/` : 実行したいPythonスクリプトを格納するためのフォルダ。
- `python-*/` : `setup.bat` 実行後に自動生成される、Python本体と仮想環境。
